SQLite3 Multiple Ciphers 2.4.0 (MIT), with SQLite 3.53.4 (public domain)
-----------------------------------------------------------------------
https://github.com/utelle/SQLite3MultipleCiphers  (NuGet: SQLite3MC.PCLRaw.bundle 2.4.0, MIT)

SQLite3 Multiple Ciphers is the SQLite database engine, extended with page ciphers, in one native library per platform
(sqlite3mc.dll, libsqlite3mc.so, libsqlite3mc.dylib, sqlite3mc.a on iOS). Bee Memory Bank loads it WITHOUT a key: its
database files stay plain SQLite files that any SQLite 3 can open.
